# Kullanılan dış dosyalar

Oyundaki bütün 3B modeller (stand, parkur, çubuk, top, halat, ağaçlar, bank, lamba),
dokular (top desenleri, halat lifleri, parkur) ve sesler kod içinde üretilir.
Hazır model, doku ya da ses dosyası kullanılmadı.

| Dosya | Kaynak | Lisans |
|---|---|---|
| Fredoka yazı tipi | `@fontsource/fredoka` (Google Fonts) | SIL Open Font License 1.1 |
| Nunito yazı tipi | `@fontsource/nunito` (Google Fonts) | SIL Open Font License 1.1 |
| Outfit yazı tipi | `@fontsource/outfit` (Google Fonts) | SIL Open Font License 1.1 |
| Three.js | `three` | MIT |
| PWA simgeleri (`public/icons`) | Bu projede çizildi | Projeyle aynı |
